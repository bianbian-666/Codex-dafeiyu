- 主动开启控制模式，WASD 按逐帧时间移动、斜向归一，左键连续抛物线投饭；独立的碎碗散饭视频来自已确认素材。落点使用投出时的脚底地面，后续移动不改变这次地面；限制三碗，一键清理，Esc／切换应用退出。
