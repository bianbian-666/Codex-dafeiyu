# Codex-dafeiyu

我们codex用户也要有自己的大肥鱼！

## 启动、隐藏与退出

完整解压 Windows x64 便携包，双击 `Codex-dafeiyu.exe`。无需 DSH，也无需另装 Node.js。请先安装并使用 ChatGPT 账号登录 Codex，以使用额度、状态和聊天。

管理窗口可通过任务栏切换；关窗后保留托盘图标。托盘可以重新打开窗口、显示/隐藏桌宠、查看额度、说一句话或退出。重复启动只唤出当前管理窗口。没有开机自启。

点击、拖拽、甩抛和右键动作菜单沿用 dsh-pet 的交互。全屏应用处于前台时自动隐藏，退出全屏后恢复；实际表现会受到系统、显示器和全屏模式影响。

## 额度、状态与碎碎念

- 看额度：每 5 分钟查询一次，手动刷新会立即查询。不调用模型。分别显示接口实际提供的时间窗口、剩余额度和重置时间；未登录、API Key 登录、不提供窗口或网络失败会显示说明。
- 钱袋动作：按所有窗口中最高已用比例分为 0–20%、20–40%、40–60%、60–80%、80–100% 和 100% 六档。
- 工作状态：每 2 秒只读本地记录。思考、写文件、命令、搜索、图片、回复等细分文字复用六组动作；多个任务优先显示等待状态。短操作可能略过；这些状态不是模型内部思维。
- 碎碎念：空闲时每 10 分钟播放本地语录，工作中暂停自动插话。不联网、不消耗模型额度。右键“动作”里的碎碎念有相应台词。
- 打开 Codex：播放敬礼与气泡，尝试恢复已运行的窗口或启动客户端。自定义安装可配置 `CODEX_PET_APP_PATH`。
- 重置查询：手动访问第三方监测站，只有有效的预告时间窗口才提示预计时间；暗示、概率、历史重置不当作新预告。网络失败单独提示。

## 和本鱼聊天

右键桌宠选择“和本鱼对话”，或在管理窗口输入。仅主动发送才调用当前账号的 Codex 模型。

新用户默认“自动”，使用账号模型列表中的可用 low 模型，不固定版本名。可手动改为最低版本 Sol 或 Luna；未提供该系列时会报错，并且不会自动换模型重发。升级保留旧选择；遇到系列不可用时可主动改为“自动”。

“展开对话”查看历史，用下拉框切换聊天，“＋新建聊天”创建独立上下文。刷新、关闭窗口和软件重启会保留历史。桌宠右键与管理窗口共用当前会话；每条最多 2000 字，发送最近最多 3 轮有效历史。

“关联 Codex 对我的了解”可关闭。展开“关于我的画像”预览摘要，补充身份、兴趣、称呼或沟通偏好。补充只保存在桌宠，不修改 Codex 的原始记忆。软件只提取个人信息和偏好栏目，不把一般操作指南作为画像；不存在的记忆不会自动获知。

聊天回复逐字显示，空闲连接保留最多 5 分钟；保留连接本身不生成回复。断网、账号错误或模型超时会显示错误；为避免重复消耗额度，不自动重发。

## 数据和修改

用户数据：`%APPDATA%\CodexPet\data`。与程序安装目录分开，中文与空格路径均受支持。

| 文件 | 用途 |
| --- | --- |
| `quotes.json` | 自定义语录；保存后下次说话生效 |
| `dsh-pet/main-config.jsonc` | 大小、位置、是否漫游与功能周期；修改后右键重载或重启 |
| `pet-conversations.json` | 会话历史、当前会话、模型模式、记忆开关与画像补充 |
| `%APPDATA%\CodexPet\app.log` | 本地诊断日志 |

升级前退出软件，备份数据目录，完整解压新版。不要把上游原版直接覆盖到本修改版。源码包、便携包均不附带作者的账号与用户数据。

特殊环境变量：`CODEX_PET_CODEX_PATH` 指向 Codex CLI；`DSH_PET_CODEX_PATH` 为兼容旧名称；`CODEX_PET_APP_PATH` 指向 Codex 桌面程序；`CODEX_HOME` 指向自定义 Codex 数据目录。通常无需配置。

v1.3.3 起名称统一为 `Codex-dafeiyu`，程序为 `Codex-dafeiyu.exe`。用户数据目录仍沿用 `%APPDATA%\CodexPet`，无需搬动聊天或设置。请先退出旧版，再启动新版。

v1.3.4 更新白饭与 token 台词。含有旧默认台词的语录文件会先备份到 `quotes.before-white-rice-v1.json`，再替换已知旧句并加入新台词；自定义语句保留。`quotes-upgrade-state.json` 记录迁移完成，之后可自由编辑、删除语录。无效 JSON 不会被覆盖。
