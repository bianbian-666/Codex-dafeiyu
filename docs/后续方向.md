# 待讨论功能

以下是用户提出的后续方向，本次仅完成语录和聊天优化，不实现这些功能。

## DDL 提醒

- 理解“每周 X 提醒我做……”和“某任务的 DDL 是……，提前 X 小时提醒我”等输入。
- 支持单次、重复规则、时区及重启后的持久化。
- 提醒需要持续可见；如何与短时气泡共存尚未确定，先讨论交互再实现。

## 桌宠控制与扔白饭

- 主动开启控制模式后，用 W/S/A/D 控制大肥鱼，复用奔跑动作。
- 鼠标左键扔出一碗白饭，按连续抛物线运动；落点与鱼所在的水平地面一致。
- 落地有碗碎、饭撒的连贯特效，可以覆盖桌面图标；不能使用低帧率动画。
- 开发时需要讨论控制模式退出方式和鼠标事件范围，避免影响正常打字、点击。
