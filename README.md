# 蓝色大肥鱼 Codex 桌宠 🐟

## 我们codex用户也要有自己的大肥鱼！

基于 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 与 [GPT-Niang](https://github.com/T7moris/GPT-Niang) 魔改的 Windows Codex 独立桌宠。感谢两个项目的作者和贡献者：dsh-pet 提供桌宠框架、角色和动画；GPT-Niang 提供只读额度后端。另感谢 [dafeiyu-persona](https://github.com/ERUIHNIYHBKBNF/dafeiyu-persona) 的人设参考。

支持透明动画、点击拖拽、额度查看、工作状态、本地语录、多会话聊天、管理窗口与全屏保护。当前发布版本 v1.3.2，完成 122 项自动检查及 Windows x64 便携包实测。

源码和发布包正在整理上传，完成后会提供完整使用说明、兼容性范围、许可证及下载项。
